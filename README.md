# ☕ Кофейный Оракул — CofeeGushya · v2.1

Браузерная игра «Гадание на кофейной гуще»: идл-плантации, мистическая кофейня с гостями, обжарка и алхимический тигель, сундучки с ингредиентами, интерактивный ритуал варки, процедурная гуща на Canvas, Таро «Карта Дня» и предсказания в стиле визуальной новеллы.

**Играть:** скачайте `index.html` и откройте двойным кликом — всё в одном файле, сервер не нужен.
Онлайн: https://malganis13.github.io/CofeeGushya/

## Сборка из исходников
```bash
bash build.sh   # склеит src/ в один index.html
```

## Что нового в 2.1
- **Новый баланс:** цены растут по формуле «База × 1,8…2,2^уровень» (улучшения плантаций, сундучки по ступеням уровня, рецепты тигля). Плантации открываются постепенно (ур. 3 / 6 / 10), награды за гадания и гостей скромнее, опыт для уровней растёт быстрее.
- **4 новых гостя:** Вереса — лесная травница, Ника — застенчивая поэтесса, Селеста — загадочная астролог, Морана — Хранительница Тайн. У всех 10 гостей есть любимые напитки (любимая пряность даёт бонус к оценке). Гости приходят по мере роста репутации.
- **Диалоги как в визуальной новелле:** приветствия, вопросы на выбор, ответы гостей и их размышления после гадания.
- **Мягкий звук:** общий «зал»-реверб, срез высоких частот, хрустальные колокольчики вместо резких сигналов, тихий шелест зёрен, бульканье турки, эзотерические аккорды во время гадания (можно выключить в профиле).
- **Медитативная варка:** спокойное помешивание с дыхательным кольцом и светящимся следом ложечки; ползунок пламени, термометр с золотой зоной, три подъёма пенки и закручивающаяся пенка в чашке.
- Плашка версии **v2.1** в шапке. Сохранения 1.0 и 2.0 совместимы.

## Что нового в 2.0
- **Мистическая Кофейня (вкладка «Гости»):** 6 NPC (поэтесса, алхимик, купец, ведьма, капитан, графиня) приходят с заказами. За выполнение — репутация, чаевые и фрагменты личных историй.
- **Обжарка-мини-игра:** Светлая / Средняя / Тёмная / Оракульская. Точность остановки стрелки даёт бонус к удаче следующего гадания.
- **Алхимический тигель:** смешивайте 2–3 сорта и открывайте 7 купажей-рецептов с особыми эффектами.
- **Дерево талантов:** 3 ветки × 3 таланта («Золотые руки», «Мастер уговоров» +15% чаевых, «Астральное чутьё» и др.). Очки — за уровни.
- **Профиль:** аватары, рамки и титулы («Ученик чародея», «Магистр гущи», «Повелитель судеб»…).
- **31 знак гущи** (+22 новых) с редкостью обычный / редкий / легендарный и трактовками для каждой стихии зодиака.
- **Таро «Карта Дня»** после гадания — 22 старших аркана, прямое и перевёрнутое положение.
- **Сочность:** пар с искрами над туркой, свечение урожая, тряска и вспышка сундучков; новые звуки — шорох зёрен, кипение, звон фарфора, тасование карт.
- «Кейсы» переименованы в **сундучки** — шансы открыто показаны, всё добывается в игре.
- **Сохранения 1.0 полностью совместимы** — прогресс подхватится автоматически.

## Основное
- **Плантации (идл):** 4 плантации, урожай идёт и офлайн; улучшения Полив, Удобрения, Бариста; ручной сбор со свечением.
- **Лавка:** товары, обжарка, тигель, рынок, запасы.
- **Сундучки:** «Ларчик Исиды», «Шёпот Таро», «Эликсир Афродиты», открытие ×5.
- **Ритуал варки:** зерно → чаша, пряность, амулет → размешивание → пенка в турке → переворот чашки → поиск знаков.
- **Предсказание из 4 частей** с учётом знаков, зерна, пряности, имени и зодиака; **карта для сторис** PNG 1080×1920.
- **Гримуар (📜):** история гаданий, карты Таро, заказы гостей и атлас знаков.
- Уровни, ежедневные дары, экспорт/импорт сохранения (`localStorage`).
