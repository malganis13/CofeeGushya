# ☕ Кофейный Оракул — CofeeGushya

Браузерная игра «Гадание на кофейной гуще»: идл-плантации, гача-кейсы, интерактивный ритуал варки, процедурная кофейная гуща на Canvas и предсказания в стиле романтической визуальной новеллы.

**Играть:** скачайте `index.html` и откройте двойным кликом — всё в одном файле, сервер не нужен.

## Сборка из исходников
```bash
bash build.sh   # склеит src/ в один index.html
```

## Что внутри
- **Плантации (идл):** Эфиопия Иргачеффе, Колумбия Супремо, Ямайка Блю Маунтин, Астральный Сад Оракула. Урожай идёт каждую секунду и офлайн (по разнице времени, до 4 ч + 2 ч за каждого бариста). Улучшения: Полив, Магические Удобрения, Мистические Бариста.
- **Лавка:** обжарка сырого урожая в зёрна для ритуала, продажа урожая, обмен монет на кристаллы, пряности, чаши, амулеты, сундук.
- **Кейсы:** «Ларчик Исиды» (монеты), «Шёпот Таро» (кристаллы), «Эликсир Афродиты» (премиум). Тиры S/A/B/C, таблица шансов, открытие ×5, анимации и конфетти.
- **Ритуал варки:** выбор зерна → чаша, пряность и амулет → размешивание (жест по кругу) и мини-игра с пенкой в турке → переворот чашки.
- **Гадание:** процедурная гуща (seed-генерация), 9 знаков — Сердце, Ключ, Кольцо, Корона, Змея, Башня, Птица, Полумесяц, Волк. Знаки нужно найти касанием, есть подсказка Оракула.
- **Предсказание из 4 частей:** 💖 Любовь и Страсть, 💰 Судьба и Богатство, 🔮 Тайные Знаки, ✨ Шёпот Кофе — с учётом знаков, редкости зерна, пряности, имени и знака зодиака.
- **Карта для сторис:** PNG 1080×1920 в стиле карты Таро — скачать или поделиться.
- **Гримуар:** история гаданий (узор восстанавливается по seed) и атлас знаков.
- **Прогресс:** уровни и опыт, ежедневные награды с серией из 7 дней, профиль, экспорт и импорт сохранения. Всё хранится в `localStorage`.

## Структура
| Файл | Назначение |
|---|---|
| `src/head.html` | разметка, стили (тёмная эзотерическая тема) |
| `src/core.js` | утилиты, данные игры, сохранения, звук, конфетти, звёздное небо |
| `src/fortune.js` | тексты и генератор предсказаний |
| `src/grounds.js` | процедурный генератор гущи и знаков на Canvas |
| `src/plant.js` | плантации и офлайн-доход |
| `src/gacha.js` | кейсы и шансы |
| `src/shop.js` | лавка, обжарка, рынок, сундук |
| `src/ritual.js` | ритуал варки, чтение гущи, экран предсказания |
| `src/share.js` | карта для сторис, гримуар, профиль, ежедневные дары |
| `src/main.js` | навигация, игровой цикл, запуск |

Внешних зависимостей нет: шрифты Google Fonts подгружаются при наличии сети, без неё используются системные.
